- The probe is not in the repo.

## 5. Decisions for the project owner to confirm

1. **Groq for suggestions.** ADR-006 §4.4 and `CLAUDE.md` removed Groq from answer generation and the judge. Using Groq for suggestions is the project owner's decision; the ADR/PLAN need a note.
2. **Processing order.** Suggestions run synchronously in the worker loop, after ingest. Each job can take up to ~40 s (two calls × 20 s). The next ingest has to wait. If this becomes a problem, split the process.
3. **Title.** When the title's source is not `USER`, the suggested title (first heading) replaces the file name. This is new behaviour for users.
4. **Tags and category.** Only tags that already exist in the workspace are attached; no new tags are created. `proposedCategoryName` is only stored; no category is created.
5. **Groq limits** of 30 RPM / 60,000 TPM are provisional values, not measured.

## 7. Known risks

- The model id `qwen/qwen3.8-27b` is env configuration; if it changes, reconfirm with `GET /models`.
- If Groq fails, the job falls back to `RULES_FALLBACK`; the log has `suggest_model_failed`, with no key or document content.
- Input is cut at 1500 tokens (the `SuggestDeps` default in code, no environment variable yet); output is capped at 400 tokens (`llm.suggest.max_output_tokens`).
